# 🚀 วิธีติดตั้ง

สิ่งที่ต้องมี:

- GitHub
- Supabase
- Vercel

ทั้งหมดสมัครใช้งานฟรีได้

## 1. GitHub

กด **Use this template → Create a new repository** แล้วตั้งชื่อ Repository ของตัวเอง

## 2. Supabase

สร้าง Project ใหม่ที่ [Supabase](https://supabase.com/)

จาก **Project Settings → API Keys** ให้เก็บ:

- `Project URL`
- `Publishable key` (`sb_publishable_...`)

หรือ `anon key` แบบเก่าที่ขึ้นต้นด้วย `eyJ`

> ⚠️ **ห้ามใช้ Secret key / service_role ในเว็บไซต์**

## 3. Environment Variables

ตั้งค่า:

| ชื่อ | ค่า |
|---|---|
| `VITE_SUPABASE_URL` | Project URL |
| `VITE_SUPABASE_ANON_KEY` | Publishable key / anon key |

## 4. Vercel

นำ Repository ไปสร้าง Project บน [Vercel](https://vercel.com/) แล้วใส่ Environment Variables จากด้านบน

จากนั้นกด **Deploy**

ถ้าแก้ Environment Variables ภายหลัง ให้ **Redeploy** อีกครั้ง

# 🛠️ ตั้งค่าครั้งแรก

เปิดเว็บหลัง Deploy แล้วจะเจอหน้า **Setup**

1. กด **คัดลอก SQL**
2. เปิด **Supabase → SQL Editor**
3. วาง SQL แล้วกด **Run**
4. กลับมาที่เว็บแล้วกด **ตรวจอีกครั้ง**

จากนั้นสร้างบัญชีที่

**Supabase → Authentication → Users → Add user**

แล้วเพิ่มอีเมลนั้นเข้า Admin ด้วยคำสั่ง:

    insert into admins (user_id)
    select id from auth.users where email = 'อีเมลของคุณ@example.com';

แนะนำให้ปิด **Allow new users to sign up** หลังสร้างบัญชีของตัวเองเรียบร้อยแล้ว

ถ้าอยากมีข้อมูลตัวอย่าง สามารถรัน `supabase/seed.sql` ได้ แต่ไม่จำเป็นค่ะ

# ⚠️ กฎการใช้งาน

Template นี้ทำขึ้นมาเพื่อให้ **นำไปทำเว็บของตัวเองได้ฟรี** ค่ะ

## ❌ ห้ามนำไปขาย

ห้ามนำโค้ดหรือ Template นี้ไป:

- ขายต่อ
- แจกต่อโดยอ้างว่าเป็นผลงานของตัวเอง
- ดัดแปลงแล้วขายเป็น Template อื่น
- นำไปทำเว็บสำเร็จรูปขาย

## ❌ ห้ามใช้เชิงพาณิชย์

ห้ามนำ Template นี้ไปใช้เพื่อหารายได้จากการให้บริการ เช่น

- รับทำเว็บไซต์
- รับทำเว็บให้ลูกค้า
- ขายเว็บไซต์
- ใช้เป็นส่วนหนึ่งของบริการรับทำเว็บ

> **เอาไปทำเว็บของตัวเองได้ แต่ไม่อนุญาตให้นำไปทำเป็นสินค้าหรือบริการของตัวเองค่ะ**

## ♡ แก้ไขเพื่อใช้ส่วนตัวได้

สามารถแก้ไขได้ตามต้องการ เช่น

- ทำธีมใหม่
- เปลี่ยน UI
- เปลี่ยนสี / ฟอนต์
- จัด Layout ใหม่
- เปลี่ยนรูปและเนื้อหา

ขอเพียงเป็นการแก้ไขเพื่อ **ใช้กับเว็บของตัวเอง** และไม่นำไปขายหรือรับทำเว็บให้คนอื่น

## 🚨 การละเมิด

หากพบการนำ Template ไปขายต่อหรือใช้เชิงพาณิชย์โดยไม่ได้รับอนุญาต ทางเราขอสงวนสิทธิ์ในการ:

- ดำเนินการตามกฎหมาย
- เรียกร้องค่าเสียหาย / ค่าปรับ
- Blacklist ผู้ละเมิด
