# Artist Café — เว็บพอร์ตโฟลิโอและคิวงานสำหรับฟรีแลนซ์

เว็บร้านฟรีแลนซ์แบบน่ารัก (วาดรูป ออกแบบ ถ่ายภาพ ฯลฯ) มีหน้าแรก เมนูงาน คิวงาน แกลลอรี่ รีวิว ช่องทางติดต่อ และหลังบ้านสำหรับจัดการทุกอย่างเอง
**ไม่ต้องติดตั้งโปรแกรม ไม่ต้องใช้ Terminal ไม่ต้องแก้โค้ด** ทำทั้งหมดผ่านเบราว์เซอร์ (มือถือก็ทำได้)

ทุกคนที่สร้างจาก Template นี้จะได้ **เว็บของตัวเอง + ฐานข้อมูล Supabase ของตัวเอง** ไม่มีข้อมูลหรือฐานข้อมูลกลางร่วมกัน

สิ่งที่ต้องมี: บัญชี GitHub, Supabase และ Vercel (สมัครฟรีทั้งหมด)

---

## 1) สร้าง Repository จาก Template

1. เปิดหน้า Repository นี้บน GitHub
2. กดปุ่มสีเขียว **Use this template** → **Create a new repository**
3. ตั้งชื่อ (เช่น `my-art-cafe`) แล้วกด **Create repository**

## 2) สร้างโปรเจกต์ Supabase

1. เข้า [supabase.com](https://supabase.com) → **New project** ตั้งชื่อและรหัสผ่านฐานข้อมูล แล้วรอจนสร้างเสร็จ
2. ไปที่ **Project Settings → API Keys** แล้วเก็บ 2 ค่านี้ไว้
   - **Project URL** (ขึ้นต้นด้วย `https://` ลงท้าย `.supabase.co`)
   - **Publishable key** (ขึ้นต้น `sb_publishable_`) หรือ anon key แบบเก่า (ขึ้นต้น `eyJ`)
3. ห้ามนำ **Secret key / service_role** มาใช้ในเว็บ เว็บจะไม่ยอมเริ่มทำงานถ้าใส่ผิด

## 3) ตั้งค่า Environment Variables

ใช้ชื่อตัวแปรตามนี้พอดี:

| ชื่อ | ค่า |
| --- | --- |
| `VITE_SUPABASE_URL` | Project URL |
| `VITE_SUPABASE_ANON_KEY` | Publishable key (หรือ anon key) |

## 4) เชื่อมกับ Vercel

1. เข้า [vercel.com](https://vercel.com) → **Add New → Project** → เลือก Repository ที่สร้างในข้อ 1
2. Vercel ตรวจเจอว่าเป็น Vite เอง ไม่ต้องแก้ Build Settings
3. เปิดส่วน **Environment Variables** ใส่ 2 ตัวแปรจากข้อ 3

## 5) Deploy

กด **Deploy** รอสักครู่ แล้วกด **Visit** เพื่อเปิดเว็บ

> ถ้าเพิ่ม/แก้ Environment Variables ทีหลัง ต้องไปที่ **Deployments → Redeploy** ค่าใหม่จึงจะมีผล

## 6) เปิดเว็บและทำ Setup

เปิดเว็บแล้วจะเห็นหน้า **Setup** (ครั้งแรกเท่านั้น):

1. กด **คัดลอก SQL**
2. กด **เปิด SQL Editor** (หรือเข้า Supabase → SQL Editor → New query) แล้ววาง SQL
3. กด **Run** แล้วกลับมากด **ตรวจอีกครั้ง**

จากนั้นสร้างบัญชีเจ้าของร้าน:

1. Supabase → **Authentication → Users → Add user** ใส่อีเมลและรหัสผ่าน (ติ๊ก Auto Confirm User)
2. Supabase → **SQL Editor** รันคำสั่งนี้ (แก้อีเมลเป็นของคุณ)

```sql
insert into admins (user_id)
select id from auth.users where email = 'อีเมลของคุณ@example.com';
```

3. แนะนำ: Authentication → Sign In / Providers → ปิด **Allow new users to sign up** เพื่อไม่ให้คนอื่นสมัครบัญชีได้
   (แม้สมัครได้ ก็ไม่มีสิทธิ์เป็นแอดมิน เพราะสิทธิ์มาจากตาราง `admins` เท่านั้น)

อยากได้เมนูงานตัวอย่างไว้ดูหน้าตา: รันไฟล์ `supabase/seed.sql` เพิ่ม (ไม่บังคับ)

## 7) ใช้หลังบ้านเพื่อใส่ข้อมูลของคุณ

เปิด `https://เว็บของคุณ.vercel.app/#/admin` แล้วเข้าสู่ระบบ

- **โปรไฟล์ / ตั้งค่าร้าน**: ชื่อร้าน ข้อความต้อนรับ สถานะรับงาน เสียงปุ่ม
- **ประเภทงาน / เมนูงาน**: เมนู ราคา ระยะเวลา และขั้นตอนมาตรฐาน (ตั้งชื่อขั้นตอนเองได้ แล้วเลือกหมวดสถานะ 4 หมวด: รอดำเนินการ / ยืนยันงาน / กำลังดำเนินการ / รอตรวจสอบ ส่วน "เสร็จสิ้น" ระบบคิดให้เมื่อครบ 100%)
- **แกลลอรี่ / คิวงาน / รีวิว / ช่องทางติดต่อ**: เพิ่มข้อมูลจริงของคุณเอง
- **ลายน้ำ** (ตั้งค่าร้าน): เปิด/ปิดแยกแกลลอรี่และเมนูงาน เลือกข้อความหรือรูป PNG ปรับความโปร่งใส ขนาด และตำแหน่ง 9 จุด มีกรอบตัวอย่างให้ดู ลายน้ำจะถูกฝังลงในรูปตอนอัปโหลด (รูปที่อัปโหลดไปก่อนหน้านี้จะไม่ถูกเปลี่ยนย้อนหลัง)
- **อัปโหลดรูป**: ลากไฟล์มาวาง (คอมพิวเตอร์) หรือแตะเพื่อเลือก (มือถือ/iPad) แล้วจัดตำแหน่ง ซูม และตัดรูปก่อนอัปโหลดจริง
- **ธีม**: มีปุ่ม "คืนค่าเริ่มต้น" ของธีมที่เลือกอยู่ เลือกชุดตกแต่ง Strawberry, Matcha, Chocolate หรือปรับสีและฟอนต์

ข้อมูลของร้าน (ชื่อ รูปผลงาน คิว รีวิว ช่องทางติดต่อ) คุณเป็นคนใส่เองเสมอ Template ไม่มีข้อมูลปลอมให้
ส่วนของตกแต่ง (สติกเกอร์ ลาย ธีม) แถมมาในตัวเว็บเป็นภาพวาดต้นฉบับ ไม่ต้องอัปโหลดเอง

## อัปเดตเว็บเมื่อมีเวอร์ชันใหม่

การเปลี่ยนแปลงฐานข้อมูลอยู่ในโฟลเดอร์ `supabase/migrations/` (เรียงเลข 001, 002, …) และทุกไฟล์รันซ้ำได้อย่างปลอดภัย
ถ้าติดตั้งไว้แล้ว ให้รันไฟล์ใหม่ตามลำดับใน SQL Editor: `003_reviews_multiple` → `004_step_categories` → `005_queue_customer_facebook` → `006_watermark_settings` → `007_rich_text_limits` → `008_queue_gallery_category` → `009_gallery_album_pin_contact_url` (ข้ามไฟล์ที่เคยรันแล้วได้) ติดตั้งใหม่ไม่ต้องทำอะไร (หน้า Setup คัดลอก SQL ครบทุกไฟล์ให้) ผู้ที่อยู่เวอร์ชันล่าสุดแล้วไม่ต้องรันซ้ำ ไฟล์ 009 เพิ่มอัลบั้ม/หลายรูป/ปักหมุดในแกลลอรี่, ลิงก์การติดต่อในคิว (รับลิงก์ใดก็ได้ ลิงก์ Facebook เดิมยังใช้ได้), และธีม Blue/Yellow/Oreo ลิงก์การติดต่อของลูกค้าเป็น "เฉพาะแอดมิน" เป็นค่าเริ่มต้น และเลือกแสดงสาธารณะได้ในหน้าแก้คิว

เมื่อมีเวอร์ชันใหม่ให้ดึงโค้ดใหม่เข้า Repository ของคุณ (GitHub: Sync fork / เปรียบเทียบกับ Template) แล้วรันไฟล์ migration ใหม่ใน SQL Editor ตามลำดับ ข้อมูลเดิมไม่ถูกลบ

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
| --- | --- |
| เห็นหน้า "ยังไม่ได้เชื่อมต่อ Supabase" | ตรวจชื่อและค่าของ Environment Variables แล้ว Redeploy |

| อัปโหลดรูปไม่ได้ | ตรวจว่ารัน SQL ครบแล้ว (สร้าง bucket `cafe-media`) และรูปไม่เกิน 8 MB |

## สำหรับนักพัฒนา (Local Development)

ผู้ใช้ทั่วไปข้ามส่วนนี้ได้

- Stack: React 18 + Vite 5, react-router (HashRouter), Supabase (Auth, Postgres + RLS, Storage)
- สิทธิ์แอดมิน: ตาราง `admins` + ฟังก์ชัน `is_admin()` และ RLS บังคับทุกการเขียน

```bash
npm install
cp .env.example .env     # ใส่ VITE_SUPABASE_URL และ VITE_SUPABASE_ANON_KEY
npm run dev
npm test                 # ทดสอบ logic และตรวจความพร้อมของ Template
npm run build
```

- เพิ่มการเปลี่ยนแปลงฐานข้อมูล: สร้างไฟล์ใหม่ `supabase/migrations/NNN_name.sql` (ดู `supabase/migrations/README.md`) แล้วรัน `node scripts/build-schema.mjs` เพื่ออัปเดต `supabase/schema.sql` (ไฟล์นี้สร้างอัตโนมัติ ห้ามแก้ด้วยมือ)
- ห้ามใส่ข้อมูลส่วนตัว, URL/คีย์จริง, `service_role` หรือ UUID ของแอดมินลงใน Repository (มีเทสต์ตรวจให้)
